⚖️ 混同注意｜CSRF

Web・サーバセキュリティシラバス用語

CSRF

Cross-Site Request Forgery
一言でいうと

🎯 支援士ではここを見る

CSRFトークン照合や再認証。Cookieが自動送信される点が核心。

⚖️ 混同注意｜XSS

CSRFは正規利用者の権限で意図しない要求を送らせる。XSSは攻撃者のスクリプトを被害者ブラウザで実行させる。

暗号・PKIシラバス用語

共通鍵暗号

一言でいうと

🎯 支援士ではここを見る

⚖️ 混同注意｜公開鍵暗号

⚖️ 混同注意｜共通鍵暗号

公開鍵と秘密鍵のペアを利用。大量データは共通鍵暗号、鍵共有等に公開鍵暗号を使うハイブリッド方式も重要。

デジタル署名

Digital Signature

⚖️ 混同注意｜MAC

MAC

Message Authentication Code
一言でいうと

共通の秘密鍵を使ってメッセージの完全性・真正性を確認する仕組み。

🎯 支援士ではここを見る

⚖️ 混同注意｜デジタル署名

MACは秘密鍵を共有するため第三者が署名者を検証する用途には向かない。デジタル署名は秘密鍵で署名し公開鍵で検証。

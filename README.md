# 情報安全確保支援士 過去問解説サイト

令和6年度秋期の午後問題（PM2 PDF）を学習用データとして追加したベース版です。

## 収録
- 問1：インシデントレスポンス
- 問2：ドメイン名変更とメールセキュリティ
- 問3：Webスキミングによるクレジットカード情報漏えい
- 問4：Webサイトのセキュリティ診断

問題本文は著作権に配慮してサイトへ転載せず、テーマ・要約・学習ポイント・関連知識を収録しています。
問題本文と正式な解答例はIPA公式の試験資料を参照してください。
